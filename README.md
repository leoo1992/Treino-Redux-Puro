# Treino Redux Puro

Exercício de estudo para praticar os fundamentos do Redux sem depender de uma interface React. O repositório organiza exemplos de estado, reducers e ações em JavaScript.

## Stack
- JavaScript
- Redux
- HTML e CSS

## Como executar
Abra `index.html` no navegador e explore os exemplos. O repositório não declara um script npm de execução.
